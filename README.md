# Altered Run

TheoSwap showcase game #1: a one-thumb endless runner (Phaser 3 + TypeScript + Vite).
See [PLAN.md](PLAN.md) for the design and milestones.

```bash
npm install
npm run dev      # http://localhost:5180 (add ?debug for the FPS meter)
npm run build    # static site in dist/
```

Controls: tap = jump (tap again in the air with the Feather trinket), swipe right = attack, swipe down = slide / fast-fall.
Keyboard: Space/Up jump, Right/X attack, Down slide.

Licensed art packs go in `public/assets/vendor/` (git-ignored, must not be redistributed).
